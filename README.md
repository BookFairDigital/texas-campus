# Texas Campus — Step 1 Homepage

This is the first static homepage prototype, based on the approved Texas Campus black/red design direction.

## Files
- `index.html` — page structure and content
- `styles.css` — colors, cards, responsive layout and CSS-made dashboard illustration
- `script.js` — mobile navigation and sample View Details dialog

## Run locally
1. Download and extract the ZIP file.
2. Open the extracted `texas_campus_step1` folder.
3. Double-click `index.html` to preview in a browser.
4. For editing, open the folder in Visual Studio Code. You can optionally use the Live Server extension and choose **Open with Live Server**.

## Important
- The prices shown are sample values only.
- Student login, payment processing, order placement, admin approval, protected course access and Google Drive LMS integration are not implemented in Step 1.
- The logo in this prototype is a simple CSS/SVG placeholder. Replace it with the client's original transparent PNG/SVG logo when the approved asset is available.
- The Google Fonts import needs an internet connection; the page falls back to common system fonts if unavailable.
- Before accepting bank transfers, verify the account details with the account owner and display them only on the intended checkout/payment instructions.
