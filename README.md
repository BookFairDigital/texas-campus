# Texas Campus — Premium UI Update

## Open the website
1. Extract the ZIP file.
2. Open the `texas_campus_step2_updated` folder.
3. Double-click `index.html` to view the homepage.
4. Use the Courses navigation or open `courses.html` to view the 12-course catalog.

## Included in this visual update
- Updated Texas Campus logo image supplied by the owner.
- Dark black/red premium styling with motion effects for dashboard, category art, robot, and course cards.
- Navigation links to Home, Courses, About, Corporate Training, and Inquiries sections.
- Redesigned Student Log In and Admin Panel Login preview modals.
- Bank details removed from the public footer; WhatsApp contact retained with a WhatsApp-style icon.
- Course catalog still includes 8 Digital Accounting and 4 AI for Accounting courses, category filters, View Details and Buy Now links.

## Important
This is still a front-end prototype. Student/admin authentication, order storage, receipt upload, bank-payment verification, and automatic course access are not connected yet. The login modals clearly indicate that backend setup is pending. No password is saved by this prototype.
